# WebAuditX
Web Auditing tool for Non Technical People

##Module 4: Website Optimization Tools

FR-T01 – Image Compression Tool
Compress uploaded images while maintaining visual quality.

FR-T02 – CSS Minifier
Minify CSS code and files.

FR-T03 – JavaScript Minifier
Minify JavaScript code and files.

FR-T04 – Performance Optimization Suggestions
Analyze a website URL and provide actionable optimization recommendations.

FR-T05 – HTML Minifier
Minify HTML code by removing unnecessary whitespace and comments.

FR-T06 – Meta Tag Generator
Generate SEO-friendly meta tags.

FR-T07 – Robots.txt Generator
Generate robots.txt files based on user inputs.

FR-T08 – Sitemap Generator
Generate XML sitemap files from URLs.

FR-T09 – Text-to-HTML Converter
Convert plain text content into structured HTML.
